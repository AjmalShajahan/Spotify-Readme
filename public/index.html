Usage & Options

The builder includes every supported option. You can also edit these query parameters directly in the generated URL.

theme
Default: light. Choose light, dark, or any of the four Catppuccin flavors shown in the builder.
spin
Default: false. Set to true to spin the album art.
scan
Default: false. Set to true to show a Spotify Code.
rainbow
Default: false. Set to true for rainbow equalizer bars.

theme=catppuccin is shorthand for theme=catppuccin-mocha. See the complete setup and deployment guide.
